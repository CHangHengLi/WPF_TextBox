# TextBox控件详解演示

这个项目是WPF TextBox控件的详细教学演示应用，用于展示TextBox控件的各种特性和使用方法。

![image](https://github.com/user-attachments/assets/6c1dc701-ec08-440c-8973-34f98ae77862)

## 项目内容

本项目详细展示了TextBox控件的以下功能：

- 基本属性与功能
- 输入控制
- 文本选择与操作
- 滚动支持
- 数据验证
- 撤销/重做支持
- 文本绑定
- 样式与模板
- 应用场景示例

## 如何使用

1. 克隆或下载本仓库
2. 使用Visual Studio打开项目
3. 构建并运行应用程序
4. 通过左侧导航菜单切换不同功能页面

## 运行环境

- .NET 8.0
- Windows

## 项目结构

- `App.xaml/App.xaml.cs`: 应用程序入口
- `MainWindow.xaml/MainWindow.xaml.cs`: 主窗口和导航框架
- `Resources/`: 包含样式和资源文件
- `Pages/`: 包含各个功能演示页面
